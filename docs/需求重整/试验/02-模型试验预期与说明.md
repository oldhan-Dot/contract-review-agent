# 合成合同模型试验

状态：样本和调用脚本已准备，尚未完成真实模型调用；不属于真实合同效果验收。

## 样本预期

| 情形 | 预期 | 判断边界 |
|---|---|---|
| 交付当天全额付款、无需验收 | 高风险 | 我方为采购方，付款缺少验收前置条件 |
| 定制成果和源码全部归乙方，仅给一年许可 | 高风险商业风险 | 与明确的定制采购权属目标冲突，不笼统声称所有供应商保留权属都违法 |
| 我方赔偿无上限、对方完全免责 | 高风险 | 需结合我方角色、责任上限和双方法律义务分析，不只匹配“甲方” |
| 保密至终止后三年 | 不应报“缺少保密期限” | 中文数字期限也是期限 |
| 不可抗力五个工作日内通知 | 不应报“未明确通知时效” | 中文数字及工作日表述有效 |
| 企业名称、编号为虚构 | 不推断经营异常或真实信用状态 | 未提供任何信用查询结果 |

这份短文本只验证一次调用、输出结构和证据引用，不估计召回率、误报率或真实合同审查能力。建议方向和依据仍需人工复核。

## 试验怎么运行

项目根目录执行：

```powershell
# 默认仅检查配置，不调用网络，不修改 .env。
.\.venv\Scripts\python.exe docs/需求重整/试验/probe_model.py

# 配置准备好后才运行，发送的仅是同目录的合成合同。
.\.venv\Scripts\python.exe docs/需求重整/试验/probe_model.py --run
```

脚本复用项目已配置模型服务。只检查启用状态和配置是否存在，不打印密钥；不修改业务代码、任务状态或数据库。真实合同后续另行提供，本脚本不会查找或上传现有业务文件。

脚本检查返回 JSON、风险等级、必需文字字段和每项证据是否为样本原文子串。结果写到本目录 `model_probe_result.json`。结构/证据通过仅是机器检查，不代表风险判断正确；需人工对照上表核验误报、漏报、建议可用性及依据表述。
