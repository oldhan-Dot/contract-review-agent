# 产品决策记录

日期：2026-10-15。来源：用户对推荐方案回复“好的”，接受本表所列方向；这是产品约定，不代表功能已经实现或试验已通过。

| 事项 | 已确认决策 |
|---|---|
| 数据权限 | 业务仅看本人任务；法务查看并复核全部送审任务；管理员维护配置、规则、重试，不能代替法务确认 |
| 送审信息 | 必填文件、合同类型、我方甲/乙角色；申请人取当前身份；主体名称、金额先提取，缺失提示 |
| 批量操作 | 先支持管理员批量重试，用户批量导出其有权查看的报告 |
| 规则与模板 | 使用有来源的清单和示范条款，区分企业要求、谈判建议、法律依据，先覆盖原始任务书场景，不追求数量 |
| 企业异常 | 演示使用显式模拟数据，无查询结果显示未核实，不接入未经确定的真实企业信用服务 |
| Word 分页 | 保留 DOCX 原件、转 PDF 预览；用户已补充由其协助完成开发试验转换，不再为等待本机转换工具暂停设计。排版、页码和映射仍需验证，最终产品转换方式另定 |
| 模型审查失败 | 有限自动重试后仍失败则受阻，保留规则结果，允许人工触发重试，不显示完整审查完成 |
| 仅建议失败 | 不丢弃风险，允许重试或法务补充，确认后回写 |
| 演示环境 | 先用当前 Windows 开发机和固定浏览器，试验时记录版本 |
| 样本 | 先覆盖采购/销售/劳动的正常与风险，再补格式和异常；一份可覆盖多场景，不固定总数 |
| 性能与排期 | 实测模型、OCR、转换后再确认目标；按四阶段成果推进，不承诺旧 60 工时 |

尚未确定：具体审查资料/模板及其来源、转换与模型实际效果、浏览器版本、性能与并发预算、最终演示日期、重试次数与超时。用户已授权先写下一步 spec，验证项在草稿中保留，不声称已通过。系统导出 PDF 审查报告不由用户手工转换替代。
