# 合同审批审查系统项目流程图

```mermaid
flowchart TD
    U[用户进入前端页面] --> UP[选择并上传合同]
    UP --> API[后端接收合同]

    API --> VALIDATE{文件是否合法}
    VALIDATE -- 否 --> FAIL[显示失败原因<br/>格式错误、文件过大或文件损坏]
    VALIDATE -- 是 --> SAVE[保存到 data/uploads<br/>创建数据库任务]

    SAVE --> PARSE{识别文件格式}
    PARSE -- DOCX --> DOCX[读取段落和表格]
    PARSE -- 普通 PDF --> PDF[提取文本、页码和坐标]
    PARSE -- 扫描件 --> OCR[调用 MinerU OCR]

    DOCX --> IR[转换为统一文本结构 IR]
    PDF --> IR
    OCR --> IR
    OCR -- 解析失败 --> BLOCK[任务变为 blocked<br/>允许修复后重试]

    IR --> SPLIT[切分合同条款]
    SPLIT --> META[提取合同主体、金额、期限等信息]
    META --> REVIEW[进入合同审查流程]

    REVIEW --> RULES[确定性规则检查]
    RULES --> NEED_AI{是否需要 AI 补充判断}

    NEED_AI -- 是 --> AI[调用大模型<br/>判断风险并生成修改建议]
    AI --> AI_OK{模型调用成功}
    AI_OK -- 否 --> RETRY{是否还能重试}
    RETRY -- 是 --> AI
    RETRY -- 否 --> DEGRADED[降级：保留规则结果<br/>显示模型不可用]
    AI_OK -- 是 --> MERGE[合并规则和 AI 结果]

    NEED_AI -- 否 --> MERGE
    DEGRADED --> MERGE

    MERGE --> STORE[保存风险、证据和修改建议]
    STORE --> COMPLETE[任务状态变为 completed]
    COMPLETE --> FRONT[前端显示原文和风险卡片]

    FRONT --> LOCATE[点击风险卡片<br/>定位并高亮原文]
    LOCATE --> HUMAN[法务人工复核]
    HUMAN --> EDIT[编辑并采纳建议、添加批注]

    EDIT --> PREVIEW[预览审批意见]
    PREVIEW --> CONFIRM{确认回写}
    CONFIRM -- 否 --> HUMAN
    CONFIRM -- 是 --> WRITEBACK[写回 Mock 审批系统]

    WRITEBACK --> IDEMPOTENT[幂等检查<br/>避免重复评论]
    IDEMPOTENT --> REPORT[导出 Markdown / PDF 报告]
```

## 流程与代码目录对应关系

| 流程 | 主要代码位置 |
|---|---|
| 页面上传和结果展示 | `frontend/src/` |
| 接收请求和返回结果 | `app/api/` |
| 保存上传文件、审批系统对接 | `app/integration/` |
| DOCX、PDF、OCR 解析 | `app/parsing/` |
| 条款切分和元数据提取 | `app/structuring/` |
| 确定性规则审查 | `app/review/rules/` |
| AI 模型调用 | `app/review/llm/` |
| LangGraph 流程编排 | `app/graph/` |
| 数据库模型 | `app/models/` |
| 配置、数据库连接和日志 | `app/core/` |
