## 文件与流程

| 文件 | 职责 |

| app/services/pdf_preview.py | 校验原件哈希、渲染指定页为 PNG、限制最大渲染尺寸 |

页面流程：详情提供已存 IR 与证据 → 前端按当前页请求受保护 PNG → 根据同一 IR 的页面尺寸与行框叠加高亮 → 点击框选择卡片/点击卡片翻页定位。

没有引入额外前端依赖。后端使用已有 PyMuPDF，前端获取 blob 后生成 object URL；不能直接用不带身份头的图片地址跳过鉴权。

## 页图接口

`GET /api/tasks/{task_id}/pages/{page_no}?review_version=1&file_id=...&scale=1.5`

- 必须携带现有身份头；业务用户只能访问自己的任务，法务/管理员按原权限访问。
- review_version 必须为当前任务版本，file_id 必须为快照原件及当前最新 PDF 附件。
- 重新读取原件并核对既有 MD5，防止磁盘文件被替换后继续使用旧证据。MD5 用于一致性检查，不作为安全签名。
- 页码越界返回 404；旧版本、错误文件或原件改变返回 409；非法比例按参数校验拒绝。
- 返回 image/png，Cache-Control 为 private, no-store；没有创建公开静态文件路径。
- scale 范围 0.5～2；后端限制最长边 2400 像素、总像素不超过约 400 万，避免极大 PDF 页面无限占用渲染内存。

首版每次换页重新渲染，不持久缓存页图；大文件/高并发性能未测，后续需要时加入按原件哈希隔离的受控缓存。

## 高亮与交互

- 以 Anchor 全文字符区间与 ParagraphNode/LineBox 的范围相交，得到该页的证据行框。
- 坐标除以原页面宽高变成百分比，缩放时和原图同步变化，不使用固定像素偏移。
- 跨页证据逐页计算；点击卡片先到证据起始页，后续页仍显示对应框。
- 黄色为风险行，选中风险强调边框；蓝色为选中字段。字段列表点击有证据的字段可返回原页定位。
- 缺项没有原文证据，不生成矩形；不能把行框称为字符级精确矩形。
- 换页中止过期请求，避免旧页返回覆盖新页；换页/卸载释放 blob URL。换身份时沿用父组件重新挂载机制。
- 原件页图是图片，不能直接选择其中的文字；切换文字视图可阅读提取内容。
