# 36. 原件阅读滚动位置稳定

2026-10-16，用户反馈合同原件区域的滚动条会自行上下移动。

## 原因

详情页每三秒轮询结果，替换 `document` 对象。`PdfDocument.vue` 原先通过单一 getter 返回 `[pageNo, reviewVersion, file_id]` 数组，重新计算时产生新数组引用，即使三个值未改变，监听仍触发页图加载。加载过程清空图片使滚动区域收缩，图片完成后又自动定位当前选中的风险，打断手动阅读。

此外，图片加载回调无条件读取已选风险，使普通翻页或重新加载也可能触发用户没有要求的定位。

## 修复

将监听改为三个独立来源，按页码、审查版本、文件 ID 的实际值比较；普通任务轮询不重新请求相同页图。增加一次性的待定位位置，仅用户点击风险/字段时设置；跨页等待页图就绪后定位一次，完成后清除。普通加载和手动翻页不再跟随旧风险滚动。

代码位于 `frontend/src/components/PdfDocument.vue`，不改变后端、模型调用或合同数据。

## 验证

Vite 构建通过。使用现有合成文本 PDF 任务 499 进行 Edge 浏览器检查：手动滚动后经历至少两次详情轮询，页图请求次数与滚动位置保持不变；手动翻页从页顶阅读；主动点击第三页风险仍正确翻页和高亮；随后手动阅读不会再次被拉回。浏览器无运行时异常。
