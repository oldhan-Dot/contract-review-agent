# 24 — 提示词集中管理与加载

日期：2026-10-15。将模型指令从业务代码中移出，便于单独阅读、调整和版本管理。

当前需求以 [PRD](../PRD.md) 为准，技术实现以 [Spec](../SPEC.md) 为准。

## 文件职责

| 文件 | 用途 |
|---|---|
| app/prompts/contract_review.txt | 正式合同审查的系统提示词 |
| app/prompts/model_probe.txt | 独立合成样本探针的系统提示词 |
| app/prompts/loader.py | 统一 load_prompt(name)，读取 UTF-8 文件 |
| app/prompts/__init__.py | 导出公共加载方法 |

两个提示词放在同一目录分别维护，因为正式审查和历史探针的 JSON 返回结构不同，不能直接混用。

## 调用流程

```python
from app.prompts import load_prompt

prompt = load_prompt("contract_review")
# 随后将 prompt 放入 messages 中 role="system" 的 content。
```

`evaluate_model()` 继续把合同类型、我方角色和条款序列化为 user 消息。提示词文件只保存固定指令，合同正文通过原有代码传入；不把原文作为模板表达式解析。Pydantic 输出校验、证据核验和接口重试仍由 Python 负责。

加载器按自身文件位置找到目录，不依赖运行时工作目录；只接受已登记的名称。新增提示词时增加文本文件，并在 PROMPT_FILES 中登记。未知名称、文件缺失、内容为空都会明确报错，不用空提示词继续请求。

当前不缓存文件，每次审查读取一次。修改文本后下一次调用可读取新内容，已经发出的模型请求不受影响。本次业务代码切换加载器仍需让正在运行的旧后端重新加载代码。
