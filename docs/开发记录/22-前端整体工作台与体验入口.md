## 现在如何体验

已启动前端：http://127.0.0.1:5173/ 。本机 8000 被其他项目占用，本次后端使用 http://127.0.0.1:8001/docs 。

1. 业务身份在大盘点击“体验合成样例”，也可上传自己的 DOCX，并明确我方甲/乙方角色。
2. 等待自动刷新，在工作台查看规则、原文证据和提取信息。
3. 切换法务身份，编辑建议、保存草稿、下载 Markdown/PDF。
4. 当前模型未启用，样例会因 AI_NOT_CONFIGURED 显示审查不完整。确认、回写完整结论受限；自行在 .env 配好模型并重启后端，再由管理员重试。
5. 完整审查成功后，法务确认、关联模拟审批单、回写并查看模拟评论。

已保留合成样例任务 411；样例是程序生成的 DOCX，不是真实合同，也未发送至模型服务。

终端关闭后可按下面命令重新启动；两个命令分别在独立终端运行：

```powershell
pwsh -File scripts/start-backend.ps1 -Port 8001
pwsh -File scripts/start-frontend.ps1 -BackendPort 8001
```
