## 本模块完成什么

可以上传文本型 PDF，解析正文、页码、文本块和行坐标，进入已有条款切分、归类、字段提取、规则及模型审查流程。仍未实现原件在线分页预览、PDF 文本层高亮绘制、Word 转换映射和扫描件 OCR。

## 解析步骤

1. 检查文件标识/存在性，使用 PyMuPDF 打开，检查是否 PDF 及是否需要密码。
2. 逐页按文本块读取，不载入图片原始字节；块内保留文字与换行，记录每行局部字符范围。
3. 构造段落及全文，全局区间与统一 IR 保持一致；每页记录实际页号、尺寸、文本、段落索引和全文区间。
4. 将旋转页面的提取矩形变换到显示方向，坐标裁剪至可见页；记录修复、空页和复杂排版警告。
5. 正文不足 50 字符受阻；图片页没有文字或大幅图像只有少量页眉文字时，返回 OCR_REQUIRED，不把可见页眉当完整正文。

纯空白页保留页信息并提示核对；复杂表格、分栏和文本/图像混排仍需人工核对。当前没有恢复 PDF 表格结构，不能保证任意扫描/混排文档都能靠文本层完整审查。

## 坐标和证据

PDF 坐标单位是 point，OCR 坐标将使用其返回图像单位；都通过页面宽高归一化，不把 PDF point 当作固定 DPI 像素。

文字区间精确来自 IR；几何框仅到行/段落精度，QualityReport 和 Anchor 声明 PARAGRAPH。同页证据保留相交行的 bbox_list。跨页证据保留起止页、起止段落和字符位置，不把多页框拼成一个矩形；后续预览从各段落行框按页绘制。

当前页面仍是文本块阅读视图，能看页码和原文/风险文字联动，尚不能当作 PDF 原排版分页和坐标高亮验收通过。

## 上传边界和错误

沿用配置的 50MB 大小限制。DOCX 仍需至少 1KB；合法短 PDF 可能小于 1KB，改由 PDF 结构校验。加密 PDF 可以作为附件保存，但解析进入 ENCRYPTED_FILE；假 PDF 在上传时返回 415，不创建任务。

Windows 下 PyMuPDF 打开损坏路径失败可能暂时占用文件，导致清理掩盖原错误。上传校验改为读取受上传大小限制的缓冲区打开，确保临时文件可删除。

失败原因：ATTACHMENT_MISSING、ATTACHMENT_CORRUPT、ENCRYPTED_FILE、EMPTY_BODY、OCR_REQUIRED、PARSE_ERROR，由执行器保留明确原因并显示 blocked。
